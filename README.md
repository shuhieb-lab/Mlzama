# ملزمة — النسخة المرتبطة بـ Supabase

تم ربط واجهة العميل فعليًا بمشروع Supabase مستقل باسم `Mulzama`.

## ما يعمل الآن
- رفع حقيقي للملفات إلى Storage خاص وغير عام.
- إنشاء الطلبات في قاعدة البيانات.
- دعم PDF وWord وPowerPoint وJPG وPNG.
- حد أقصى 10 ملفات للطلب و50MB للملف الواحد.
- خيارات اللون، المقاس، وجه/وجهين، عدد النسخ، الصفحات، التجليد والملاحظات.
- إنشاء رقم طلب حقيقي مثل `MZ-20260904-123456`.
- الواجهة عربية RTL ومتجاوبة مع الجوال.
- واجهة افتتاحية بصرية مختصرة مع صورة مخصصة وزر مباشر لبدء الطلب.

## تشغيل الواجهة
يفضل تشغيلها عبر استضافة HTTPS. للاختبار المحلي:

```bash
python3 -m http.server 8080
```

ثم افتح http://localhost:8080/

## الرفع إلى GitHub Pages
1. افتح مستودع `Mlzama` في GitHub.
2. ارفع **محتويات هذا المجلد** كما هي، بحيث يظهر `index.html` في الصفحة الرئيسية للمستودع.
3. افتح: `Settings` ثم `Pages`.
4. اختر: `Deploy from a branch` ثم الفرع `main` والمجلد `/(root)`.
5. اضغط `Save` وانتظر ظهور رابط الموقع.

لا ترفع ملف ZIP إلى المستودع؛ فك الضغط أولًا ثم ارفع جميع الملفات الظاهرة داخل المجلد دفعة واحدة. الصور موجودة بجانب `index.html` لتسهيل الرفع.

الصورة الجديدة للواجهة باسم `hero-visual-v2.webp` ويجب رفعها مع بقية الملفات.

## ملاحظة لوحة الإدارة
قاعدة البيانات والتخزين أصبحا حقيقيين، لكن لوحة الإدارة لن تُفتح على بيانات العملاء قبل إضافة تسجيل دخول مدير آمن. الخطوة التالية هي تحديد بريد المدير ثم ربط شاشة الطلبات والتنزيل وتحديث الحالة.
